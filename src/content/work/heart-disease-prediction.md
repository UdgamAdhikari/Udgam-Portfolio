## The problem

Heart disease is often caught late. This project estimates a person's risk from their medical data, so that an assessment can prompt earlier checks and preventive care.

## What it does

- Takes 13 clinical measurements (age, chest-pain type, blood pressure, cholesterol, maximum heart rate and more) through a web form.
- Runs them through a Random Forest classifier to predict heart-disease risk in real time.
- Reports the model's accuracy and performance metrics alongside the prediction.

## Stack

- **Backend:** Python and Flask
- **Machine learning:** scikit-learn (Random Forest), Pandas
- **Frontend:** React (Vite), with Firebase Authentication for sign-in
- **Data:** the UCI heart-disease dataset
